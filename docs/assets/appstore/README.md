# App Store screenshot canvases

Generated from live captures of the native SwiftUI macOS app.

| Stem | Source capture | Suggested App Store caption |
|------|----------------|-----------------------------|
| `01-workspace` | Main three-pane workspace with crop | Preview, crop, and encode in one window |
| `02-playback` | Timeline / filmstrip scrubbing | Scrub the sequence with a live filmstrip |
| `03-color` | Color adjustments expanded | Exposure, contrast, and more — with numeric fields |
| `04-empty` | Empty / open state | Open a numbered photo sequence to begin |
| `05-controls` | Progressive disclosure (collapsed color) | Advanced controls stay tucked away until you need them |

## Sizes

For each stem, three PNG canvases are provided:

- `2880×1800` — macOS App Store (preferred)
- `2560×1600` — macOS App Store
- `1440×900` — smaller Mac display

Upload the size set that matches App Store Connect’s current requirements. Prefer `*-2880x1800.png` when available.

Raw window captures (Retina) live in `../screenshots/`.
